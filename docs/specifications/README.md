# Tài liệu yêu cầu Pha 1

Hai tệp DOCX trong thư mục này là bản đặc tả do nhóm cung cấp và được đưa vào repo để việc triển khai, review và nghiệm thu có cùng nguồn tham chiếu:

- `1_Mo_ta_bai_toan_va_nghiep_vu_co_ban.docx`: mô tả bài toán và luồng nghiệp vụ gửi xe, tra cứu, lấy xe.
- `2_Dac_ta_API.docx`: hợp đồng API, cấu trúc request/response và quy tắc lỗi.

README ở thư mục gốc và `docs/architecture.md` tóm tắt cách repo hiện thực các yêu cầu; khi cần diễn giải chính xác yêu cầu, ưu tiên đọc hai tài liệu gốc. Đặc tả API bao gồm endpoint liệt kê lượt xe phân trang bên cạnh các thao tác theo ticket. Phạm vi phiên bản Pha 1 không bao gồm giá hoặc tính phí.

Các tệp DOCX được giữ nguyên nội dung từ bản nhóm cung cấp ngày 28-10-2026.
